# 📘 [11. demoqa.com Proyecto Completo]

- **Concepto Clave Asimilado:** Aplicación integrada de todos los conceptos de Playwright contra un solo sitio objetivo.

### 🧪 PARTE A: Laboratorio Express (Mini-Proyecto Aislado)
- **Desafío:** Automation de Elements y Forms — Crear tests en demoqa.com para las secciones Text Box, Check Box, Radio Button y Web Tables, usando POM y validaciones.

**Instrucciones:**
1. POM: `TextBoxPage`, `CheckBoxPage`, `RadioButtonPage`, `WebTablePage`
2. Tests: llenar formulario, marcar checkboxes, seleccionar radio, agregar fila a tabla
3. Validar cada acción con el mensaje de salida correspondiente

### 🏗️ PARTE B: Evolución del Proyecto Principal de la Materia
- **Evolución del Software:** No corresponde directamente; este capítulo es complementario al proyecto principal. Usar como práctica integradora final.
