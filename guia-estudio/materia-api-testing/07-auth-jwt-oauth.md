# 📘 [07. Auth Testing — JWT y OAuth]

- **Concepto Clave Asimilado:** Flujo de autenticación JWT, obtención de tokens, uso en headers Authorization, refresh tokens.

### 🧪 PARTE A: Laboratorio Express (Mini-Proyecto Aislado)
- **Desafío:** Token Flow en Postman — Usar https://reqres.in para registrar usuario, extraer token, pasarlo al siguiente request.

### 🏗️ PARTE B: Evolución del Proyecto Principal de la Materia
- **Evolución del Software:** Autenticación Bancaria — Tests para login con credenciales válidas (obtener JWT), acceso a endpoints protegidos sin token (401), con token expirado (401), con token válido (200), refresh token flow.
