# 📘 [09. Data-Driven Tests @ParameterizedTest]

- **Concepto Clave Asimilado:** Test parametrizados con @CsvSource, @ValueSource, @MethodSource en JUnit 5.

### 🧪 PARTE A: Laboratorio Express (Mini-Proyecto Aislado)
- **Desafío:** Parametrized Playground — Test con 10 IDs de posts diferentes validando status 200 en todos.

### 🏗️ PARTE B: Evolución del Proyecto Principal de la Materia
- **Evolución del Software:** Data-Driven Banking — Test parametrizado con 20 cuentas, verificar que todas tengan balance >= 0. CSV con casos de transferencia (origen, destino, monto, expectedStatus).
