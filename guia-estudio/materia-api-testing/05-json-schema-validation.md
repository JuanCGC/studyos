# 📘 [05. JSON Schema Validation]

- **Concepto Clave Asimilado:** Validación programática de schemas JSON en RestAssured con `matchesJsonSchemaInClasspath`.

### 🧪 PARTE A: Laboratorio Express (Mini-Proyecto Aislado)
- **Desafío:** Schema Validator — Validar response de JSONPlaceholder contra schema estricto con `additionalProperties: false`.

### 🏗️ PARTE B: Evolución del Proyecto Principal de la Materia
- **Evolución del Software:** Schemas del Core Bancario — Validar cada endpoint del negocio contra su schema: Account, Transaction, User, Balance. Todos con `additionalProperties: false`.
