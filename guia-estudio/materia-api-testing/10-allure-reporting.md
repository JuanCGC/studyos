# 📘 [10. Allure Reporting]

- **Concepto Clave Asimilado:** Configuración de Allure, anotaciones @DisplayName, @Feature, @Story, reportes visuales.

### 🧪 PARTE A: Laboratorio Express (Mini-Proyecto Aislado)
- **Desafío:** Allure Quickstart — Agregar Allure a un proyecto Maven, generar reporte local con `mvn allure:serve`.

### 🏗️ PARTE B: Evolución del Proyecto Principal de la Materia
- **Evolución del Software:** Reporte Bancario Completo — Anotar todos los tests con @Feature("Accounts"), @Story("Create Account"), etc. Generar reporte unificado en CI/CD como artefacto.
